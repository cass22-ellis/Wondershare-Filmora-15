## 🛠 Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway** |
| Preview is choppy on 4K clips | File → Preferences → Performance → set Playback Quality to **1/2** or **1/4** |
| Export stuck at a given percentage | Disable hardware acceleration under Preferences → Performance → GPU, retry |
| AI tools greyed out | AI features require an active internet connection on first use |
| Project opens with offline media | Right click the offline clip in the Media panel → **Relink Media** → pick the file |
| Imported audio out of sync | Right click the audio clip → **Detach Audio** → re-align manually |
| Fonts missing in a template | Install the required font system wide, restart Filmora, reload the template |
